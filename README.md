# Peblo TV Mini

A mini OTT streaming platform built as part of the Peblo Full Stack Development Challenge.

## 🚀 Features

### Viewer Application
- Browse movies and TV shows
- Featured show hero section
- Movies and TV Shows filtering
- My List functionality
- Show details modal
- Video playback link support
- Responsive UI

### Admin CMS
- Add new shows
- Edit existing shows
- Delete shows
- Mark/unmark shows as featured
- Manage poster URLs and video URLs
- Dynamic content updates

## 🛠️ Tech Stack

### Frontend
- React
- JavaScript
- CSS

### Backend
- FastAPI
- Python
- Pydantic

### Database
- PostgreSQL
